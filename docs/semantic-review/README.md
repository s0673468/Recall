# Semantic review evidence

The dated files in this directory are the durable, study-content-safe evidence for a complete
Recall library review. They intentionally exclude private card text and local Anki identifiers.

- `2026-08-11-summary.json` records catalog coverage and the final action counts.
- `2026-08-11-source-ledger.json` records the public accuracy sources, dates, and supported claims
  for every reviewed concept cluster.

The review rules are defined in [`../card-golden-standard.md`](../card-golden-standard.md).
